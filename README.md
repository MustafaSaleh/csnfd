# Living Network

An interactive 3D explainer of how Cisco networking and security products work together: how data moves, where
identity is verified, where policy is authored and enforced, how threats are detected and stopped, and how trust
is re-evaluated through a session.

Independent educational visualization. Not an official Cisco product.

Everything is in [`living-network/`](living-network/):

- **Run it:** open [`living-network/index.html`](living-network/index.html) in a browser, with internet on. There is no build step and no backend.
- **Host it:** [`living-network/dist/index.html`](living-network/dist/index.html) is the same page as a single file.
- **Read more:** [`living-network/README.md`](living-network/README.md) covers the modes, presets, sources and how to rebuild.
